# Checkliste: Benötigte Inhalte & Zugänge vom Auftraggeber

Sortiert nach Dringlichkeit. „Blockiert Livegang" = ohne diese Angabe kann die
Website nicht seriös veröffentlicht werden.

## A — Blockiert Livegang

- [ ] **Logo** als SVG oder hochauflösende Datei (inkl. Nutzungsrechten)
- [ ] **Verbindliche Farbwerte** (falls vorhanden; sonst Freigabe der vorgeschlagenen Palette)
- [ ] **Genauer Vereinszweck laut Satzung** (wörtlich oder freigegebene Kurzfassung)
- [ ] **Vorstandsangaben bestätigen**: Schreibweisen, Funktionen, Vertretungsregelung
      (Vorlage: N. Sivananthan/Vorsitz, O. Thanapalasingham/Schatzmeister, S. Sathianandan/Schriftführer)
- [ ] **Bankverbindung gegen Kontoauszug bestätigen** (IBAN DE18 3845 0000 1000 2149 63, BIC WELADED1GMB, Sparkasse Gummersbach-Bergneustadt)
- [ ] **Gewünschte Verwendungszwecke** für Überweisungen (allgemein + projektbezogen)
- [ ] **Echte Projektliste**: je Projekt Titel, Ort/Region, Thema, Ausgangslage, Maßnahme, Ziel, Stand, benötigte Unterstützung, Ansprechpartner
- [ ] **Projektbilder + Bildrechte/Einwilligungen** (siehe /content/image-requirements.md)
- [ ] **Impressumsangaben** (inkl. Verantwortlicher § 18 MStV) → anwaltlich prüfen lassen
- [ ] **Datenschutzerklärung** (auf Basis des dokumentierten Technikstands) → anwaltlich prüfen lassen
- [ ] **Wunschdomain** (livingcharity.de? Inhaberschaft klären) + **Domainzugang**
- [ ] **Hostingzugang** (Anbieter, Zugangsdaten, SSL-Zertifikat/Let's-Encrypt-Option)
- [ ] **WordPress-Zugang** (Admin-Konto der Zielinstallation)
- [ ] **Ansprechpartner für Freigaben** (Name, E-Mail, Erreichbarkeit)

## B — Wichtig, kurzfristig nachreichbar

- [ ] **Freistellungsbescheid / Gemeinnützigkeitsstatus** (für Spendenbescheinigungs-Aussagen)
- [ ] **Regelung zu Zuwendungsbestätigungen** (ab welchem Betrag, wie angefordert)
- [ ] **Telefonnummer** (für Click-to-Call und Footer)
- [ ] **Verifizierte E-Mail-Adressen** (info@livingcharity.de aktiv? Weitere Postfächer?)
- [ ] **Eintragungsdatum lt. Registerauszug** („seit 2010" präzisieren)
- [ ] **Zahlen und Nachweise**: Belege für Wirkungsangaben (Zeitraum, Zählweise) —
      insbesondere Entscheidung zu den Altseiten-Zahlen (13.000 Menschen / 5.000 Unterstützer / 400 Veranstaltungen): belegen oder streichen
- [ ] **Aktuelle Veranstaltungen** (Titel, Datum, Ort, Beschreibung)
- [ ] **Vergangene Veranstaltungen** für Rückblicke (optional, mit Fotos + Einwilligungen)
- [ ] **Erste Beiträge** für „Aktuelles" (oder Freigabe, mit leerem Zustand zu starten)

## C — Optional / Ausbaustufe

- [ ] **Partner und Sponsoren** (Namen, Logos, schriftliche Logo-Freigaben)
- [ ] **Freigegebene Stimmen/Erfahrungen** (Zitat, Name, Kontext, schriftliche Freigabe) → aktiviert die Sektion „Wirkung und Stimmen"
- [ ] **Social-Media-Profile** (nur verifizierte, aktiv gepflegte)
- [ ] **Zahlungsanbieter-Entscheidung** für Online-Spenden (z. B. Spendenplattform oder PSP) inkl. Vertrag und Zugangsdaten
- [ ] **Bestehende Plugins/Themes** der Ziel-WordPress-Installation (Liste)
- [ ] **Gewünschte Sprachen** (derzeit: Deutsch; Mehrsprachigkeit wäre Ausbaustufe)
- [ ] **Transparenzseite** (Mittelverwendung mit echten Zahlen) — Struktur vorbereitet
- [ ] **Video-Material** (mit lokalen Vorschaubildern, Einwilligungen)

## Übergaberegeln

1. Jede gelieferte Angabe wird in `/content/content-status.md` von Kategorie B/C
   nach A verschoben (mit Datum).
2. Textfreigaben bitte schriftlich (E-Mail genügt).
3. Für Fotos: Datei + wer/wann/wo + Rechteinhaber + Einwilligungsnachweis.
